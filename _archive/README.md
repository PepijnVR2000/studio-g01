# Archived pages

Pages taken off studiog01.nl but kept so they can come back. GitHub Pages does not publish folders whose names start with an underscore, so nothing in here is online.

## 2026-11-removed

Removed on 13-11-2026 with Bertalan's November update. The files are the exact versions that were live before the update (commit `43641bc`).

- `work.html`, `work-01.html` to `work-05.html`: the Archive overview and its five projects.
- `playground.html`: the old Playground overview. The menu's Playground link now opens `playground-vessel.html` directly.
- `playground-gcode.html`: the G-code tool.

The images these pages use are still in `img/`.

To bring a page back: move it to the site root, update its menu to the current one (Custom design instead of "Work with us", no Archive link unless the Archive returns too), add its link to the menu on every page, and add it to `sitemap.xml`.
